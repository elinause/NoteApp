NoteApp – Python PyQt5

About the Project

NoteApp is a simple desktop note-taking application built with Python and PyQt5. It allows users to create, view, edit, update, and delete notes. Notes are saved in a JSON file so that they remain available after closing and reopening the application.

Features

Create notes with a title and content.

View saved notes by selecting their titles.

Edit existing notes.

Update note content.

Delete unwanted notes.

Save and load notes using JSON storage.

Simple graphical user interface.

Technologies Used

Python

PyQt5

Git and GitHub

Requirements

Python 3

PyQt5

Installation and Setup

Clone this repository:

git clone https://github.com/elinause/NoteApp.git

Open the project folder:

cd NoteApp

Install PyQt5:

pip install PyQt5

Run the application:

python main.py

Data Storage

The application stores notes in notes.json. The file is created when notes are saved and is used to load saved notes when the application starts.

Learning Purpose

This project was developed as a Python learning project to practise object-oriented programming, PyQt5 GUI development, lists, dictionaries, file handling, JSON serialization, and connecting signals to methods.
